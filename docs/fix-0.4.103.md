# 0.4.103: сезоны внутри торрентного пакета

Реально воспроизведено на lampac.rest в раздаче «[uni] Магическая битва / Jujutsu Kaisen [3TV+Movie]»: 59 серий, файлы из папок первого, второго и третьего сезонов получали сезон 1, одинаковые названия/кадры и одинаковый hash Timeline для одинаковых номеров серий. Папки названы «[1] Jujutsu Kaisen [tv]», «[3] Jujutsu Kaisen 2 [tv]», «[6] Jujutsu Kaisen 3-1 [tv]». Число в начальных скобках — порядок папки, не сезон.

Причина: штатный Torserver.parse распознаёт S02/Season 2, но не номер продолжения после названия; при отсутствии сезона ставит 1. Предыдущая корректировка применялась только к одиночной сопоставленной раздаче, пакеты исключались. Теперь ближайший явный сезон и совпадающее семейство папок внутри одного пакета определяются до Api.seasons и вычисления hash. Подтверждённые соответствия арок каталогу сохраняются. Нельзя считать произвольный номер папки сезоном, назначать один сезон всему пакету, затрагивать фильм/спецвыпуск или переносить уже смешанные таймкоды по догадке.

Критерии: запросы метаданных 1/2/3; разные превью, названия и Timeline S1E1/S2E1/S3E1; корректные координаты плеера; приоритет файла/ближайшей папки над внешним каталогом; существующее сопоставление арок и отдельные файлы сохранены. Воспроизведение и отметки пользователя при живой проверке не изменять.
