# Исправления после 0.5.65 — версия 0.5.66

Один проход по замечаниям пользователя. Публикация только в GitHub Pages; сервер не обновляется.

| Замечание | Изменение |
| --- | --- |
| У финальных серий объединённого сезона нет названий и кадров | TV-спецвыпуски сопоставляются с сезоном 0 по полной дате начала/окончания релиза и числу выпусков. При неоднозначности чужие кадры не подставляются. |
| «Братство» и «Дороро» показывают единственный сезон как второй и теряют метаданные | Физический номер папки отделён от номера каталога. Единственный подтверждённый релиз может иметь произвольный номер у провайдера. |
| Ванпанчмен: повтор первой серии | Реальный выпуск 0 остаётся дополнительным выпуском; данные первой серии к нему не применяются. |
| Нет «Бесконечного поезда» в меню сериала | Альтернативная ТВ-адаптация участвует в поиске сезонов, даже когда в основной истории выбран фильм. При совпадениях нескольких релизов одного года точное название имеет приоритет над общим названием франшизы. |
| Путаются номера сезонов источника и TMDB | Для Kodik сохраняется отдельная проверенная карта физический номер → релиз → сезон каталога. Меню сортируется по каталогу, исходные индексы выбора и Timeline сохраняются. При смене провайдера эта карта сбрасывается. |
| «Аватар короля»/«Военная хроника»: будущий сезон увеличивает счётчики | Заголовок использует подтверждённые вышедшие сезоны; известный будущий сезон сохраняется в расписании. Отсутствие последнего сезона источника не блокирует метаданные первого. |
| Пламенная бригада, Психопаспорт: кадры и даты есть, названия пустые | Общий загрузчик дополняет техническое «Серия N» исходным названием и отсутствующим описанием на английском, только при совпадении координат и ID эпизода. Существующий перевод сохраняется. |
| В основной истории повторяются переходы в одну карточку | Ряды франшизы показывают назначение один раз; полная карта релизов остаётся для сопоставления эпизодов. Фильмы сохраняют отдельные ID. Проморолики и рекламные кроссоверы не попадают в обычные дополнения. |
| Непонятен порядок просмотра | Отдельная нумерованная последовательность сезонов, фильмов и частей с годами, по порядку выхода. У фильма указывается альтернативная ТВ-версия, если её связь подтверждена. Это не заявленный хронологический порядок событий сюжета. |
| Части подписаны рядом с оценкой | Отдельная плашка на кадре рядом с номером серии, в сетке и списке. |
| Shikimori пишет неверное общее число сезонов/серий | Подпись «Эпизодов в релизе» относится к конкретной записи Shikimori, без неподтверждённого номера общего сезона сериала. Кэш старых подписей обновлён. |
| Shikimori «Ещё» обрывается | После каждой страницы обновляется граница штатного загрузчика Lampa. Проверены четыре последовательные страницы, остановка только на неполной странице. |
| Постеры остаются пустыми | Снятая до подключения карточки к DOM задача помечается завершённой, поэтому видимая карточка может повторно поставить изображение в очередь. |
| «Лазарь» помечен сериалом | Общий индекс аниме учитывается при классификации даже без жанров и страны в неполной карточке. Пространства ID фильмов и сериалов не смешиваются. |
| Низкое разрешение фона | Если каталог сообщает размеры изображений, для слишком маленького текущего фона выбирается доступный вариант большего разрешения. Искусственное увеличение детализации не используется. |

## Проверка и ограничения

Регрессионные проверки покрывают общие алгоритмы, штатный компонент Lampa, нулевой выпуск, сохранность обработчиков/хешей, одиночную папку №2, пять сезонов с ТВ-альтернативой, метаданные финальных спецвыпусков, резерв языка и пагинацию. Данные проверок включают фиксированные ответы; это не просмотр каждого потока и каждой озвучки.

Публичная проверка без ключей подтвердила состав релизов «Истребителя демонов» в Shikimori и 8 файлов четвёртого исходного пункта Kodik. Запросы первого и второго исходных пунктов вернули пустой ответ, поэтому живое восстановление полного меню в таком ответе не подтверждено: адаптер сохраняет исходное меню при недостатке доказательств. Личные ключи и данные аккаунта в диагностические запросы не передавались.

Если оригинального названия/описания нет и в исходном каталоге, плагин его не сочиняет. Вышедшие, но отсутствующие видео не создаются из расписания. Подтверждённые будущие эпизоды с датами остаются видимыми. Наличие пункта источника не гарантирует доступность каждой озвучки.
