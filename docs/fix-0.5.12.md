# 0.5.12 — Убрать размытую полосу значков

Причина: штатное glass--style добавляет backdrop-filter контейнеру card__icons-inner. После растяжения контейнера появляется широкая размытая полоса, а фильтр создаёт содержащий блок для абсолютного Play.

Исправление: отключить унаследованное размытие только у этого служебного контейнера; отдельные значки и их флаги сохраняются. Критерии: контейнер прозрачный и без backdrop-filter; Play по центру ширины постера и на 62% высоты; остальные значки слева без наложения. Проверить обе темы со штатным стеклом в Chromium/WebKit, десктоп и ТВ. Снимки не создавать.
