# Пересборка подборок: предложение после разбора SURS

Проверен загрузчик https://aviamovie.github.io/surs.js и его текущие модули v3/surs.js, surs_select.js (2026-11-04). Сам загрузчик не содержит каталога: модули строят discover-запросы TMDB по странам, жанрам, сетям и сортировке, в том числе KR, TR и RU. Это не отдельная база дорам или аниме.

## Предлагаемая структура

- Сериалы: сейчас выходит, новинки, высокий рейтинг; российские, турецкие, британские; криминал, фантастика, комедии. Региональные строки самостоятельны, их можно скрывать и переставлять.
- Дорамы: свежие релизы и текущие; Корея, Китай, Япония, Таиланд; романтика, триллеры/детективы, исторические. Не смешивать с анимацией, документалистикой и реалити.
- ТВ-шоу: российские реалити, ток-шоу, развлекательные; зарубежные — отдельными строками. Конкретные музыкальные/интеллектуальные/путешествия добавлять только при надёжном признаке в базе либо проверенном списке.
- KinoAPI использовать при наличии пользовательского ключа для подтверждённых стран/жанров/годов. В текущем документированном API нет фильтра по сети/стримингу и отдельного признака «шоу о путешествиях»; названия строк не должны обещать такой фильтр.
- Не переносить случайную смену названий/жанров SURS и не подключать его целиком: это меняло бы порядок, настройки и нагрузку.

## Аниме

- Полный абсолютный список провайдера → проверенные арки каталога, одинаковый слой метаданных, без смены координат воспроизведения/Timeline.
- Если провайдер отдаёт меньше серий, не создавать фиктивные сезоны. Число сезонов каталога и доступных у источника различать.
- Именованный сезон отображать двумя строками на баннере: «Сезон N», название арки.
- Общая модель релизов MAL/Shikimori для карточек, франшиз и торрентов всё ещё отдельная незавершённая работа; текущий проход не считать её завершением.
