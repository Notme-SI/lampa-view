# 0.5.1 — Постеры при прокрутке и доступность источников

- Подготавливать ближайшие ряды постеров во время движения, без блокировки всей предзагрузки одной медленной картинкой. Сохранить ограниченную очередь, качество и общий файловый кеш; не загружать весь каталог.
- В меню источников и текущем источнике показывать зелёный индикатор только после подтверждённого наличия видео. Обновлять открытое меню по результатам существующих запросов; не добавлять отдельный обход всех провайдеров.
- Проверить быструю прокрутку в Chromium/WebKit, повторное использование кеша, выбор провайдера, отсутствие ложной отметки у непроверенного источника и очистку при пустом результате.
- На ТВ убрать постоянные фильтры шапки и меток постеров в «Стекле», сохранив материал шапки из кешированного размытого фона. Размытие открытых меню и поиска сохранить; десктоп и телефон не менять. Проверить вычисленные стили всех трёх режимов.
- Сборка, обязательные тесты проекта, актуальные CI и Pages. Новые скриншоты не снимать. Физический ТВ не считать проверенным.
