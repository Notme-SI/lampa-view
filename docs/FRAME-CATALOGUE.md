# Каталог кадров

Плагин получает галереи из frames/v1/ на GitHub Pages. Каталог содержит ссылки на изображения и сведения об источниках. Ключ для его загрузки не требуется.

## Загрузка

Проверяется точный TMDB ID с типом произведения. Для записей архивов без ID используются оригинальное название и год. При неоднозначном сопоставлении галерея не выбирается.

Индекс разделён на 64 файла. Плагин загружает части, нужные открытой карточке, объединяет одновременные запросы и кеширует до восьми частей на шесть часов. При сетевой ошибке доступна последняя сохранённая копия за семь дней. Повторная попытка откладывается на минуту.

В галерее максимум 14 кадров. Метаданные готовятся до показа карточки. Если записи сериала в каталоге нет, используется существующая загрузка дополнительных кадров эпизодов через настроенный транспорт TMDB. Указанный пользователем ключ ПоискКино продолжает работать как дополнительный источник.

## Обновление

Workflow Update frame catalogue запускается ежедневно в 03.23 UTC и вручную через GitHub Actions. Он собирает FilmGrab, Bluscreens, официальные галереи Ghibli и подтверждённые разделы screenshots Wiki. Исходные связи и проверенные кадры находятся в data/frame-catalogue-seeds.json.

Сборщик сохраняет прежние записи при сбое источника и отклоняет результат, потерявший более 15% галерей. При отказе всех источников публикация прекращается. После проверки схема записывается в docs/frames/v1/, изменения отправляются в main и запрашивается сборка GitHub Pages. Версия плагина для обновления ссылок не меняется.

Для ручного обновления нужен Node.js 24. Выполните node tools/update-frame-catalogue.cjs и затем node --test tests/frame-catalogue.test.cjs.

## Формат

Каждая запись содержит тип произведения, название, год, необязательный TMDB ID, источник, адрес исходной галереи и до 14 пар img / url для миниатюры и оригинала. Общая схема и выбор части индекса определены в src/frame-catalogue.cjs. Manifest сообщает число записей, источники и время последнего успешного обновления.

Кадры остаются на сайтах владельцев. Их доступность и наличие галерей новинок зависят от этих сайтов. Последняя успешная проверка метаданных не гарантирует постоянную доступность каждого файла.
