# Требования после 0.5.25 и реализация 0.5.28

Документ объединяет уточнения пользователя из текущего чата. Поздние указания имеют приоритет над ранними. Последняя публикация: только GitHub; копии плагина на сервере не обновляются.

## Подборки

| Раздел | Итоговые правила |
| --- | --- |
| Фильмы | Подборки обычными рядами постеров внутри раздела. Без кнопки «Все подборки» и пустых плиток. Жанры и другие подходящие подборки SURS используют встроенные запросы и штатное продолжение. |
| Сериалы | Первыми идут «Популярные сейчас», «Сейчас выходят», «Премьеры <год>». Затем российские, турецкие сериалы, корейские дорамы, популярные жанры, китайские дорамы и британские сериалы. Основные ряды ограничены последними четырьмя годами и Scripted/Miniseries, порядок карточек — по популярности. Без студий, каналов, десятилетий, реалити и ток-шоу. |
| Дорамы | Встроены в сериалы. Отдельный пункт убран из основного меню и управления подборками. |
| Мультфильмы | «Популярное», «Новинки», «Высокий рейтинг», «Для всей семьи», жанры. Фильмы и сериалы объединены там, где жанр поддерживает оба формата; одинаковые ID разных форматов различаются. Без студий, каналов, отдельных франшиз вроде «Аватара»/«Джимми Нейтрона» и повторов «мультфильмы/мультсериалы» в заголовках. Студию можно открыть из карточки. |
| ТВ-шоу | Российские «Популярное», «Премьеры <год>», «Реалити и соревнования», «Разговорные и развлекательные шоу», «Высокий рейтинг». Новинки ограничены годом премьеры, остальные основные ряды — последними восемью годами и соответствующими жанрами. Без каналов и студий. |
| Настройки | Списки фильмов, сериалов, мультфильмов и ТВ-шоу строятся по текущему плану, даже до первого посещения. Старые названия удалённых строк не возвращаются. Порядок и скрытие сопоставляются также по прежним идентификаторам. |

SURS интегрирован как источник определений подборок и фильтров в существующие разделы; его исходный интерфейс отдельно не подключается. Старые прямые ссылки сохраняются для совместимости и не создают дополнительные ряды в обзоре.

## Поиск и карточки

- Шесть каталогов поиска по фильтрам: Фильмы, Сериалы, Мультфильмы, ТВ-шоу, Аниме, Аниме Shikimori.
- Страны, жанры, рейтинг, число оценок, сортировка, готовые периоды SURS и ручной диапазон лет. Shikimori сохраняет собственные форматы и статусы; неподдерживаемая страна ему не передаётся.
- Отступы текста в поле поиска исправлены. Смешанные результаты сохраняют формат фильма/сериала и продолжение страниц.
- Подборки фильмов, сериалов, дорам и ТВ-шоу отбрасывают карточки без русского названия и постера, а также явно отсутствующего backdrop. Русское name учитывается при английском title. Это правило подборок и их «Ещё»; самостоятельный поиск сторонних источников не переписывается.

## Аниме

- Исправления общие: идентификаторы и цепочки MAL/Shikimori/AniList/AniDB, проверенные TMDB episode groups, канонические сезоны и координаты эпизодов. Названия конкретных тайтлов в правилах не зашиты.
- Полные и разреженные сквозные списки делятся по проверенной карте. Дополнительно поддержан доступный хвост, который начинается далеко после первой серии, и два способа нумерации метаданных: локальный и сквозной.
- Нет искусственных эпизодов или переименования файлов. Сохраняются исходные обработчики воспроизведения и ключи Timeline. Показываются только доступные эпизоды.
- До четырёх доступных сезонов — кнопки; больше четырёх — свёрнутый список. Номер сезона сверху, число доступных эпизодов снизу, без «/ N». Кнопки не переименовываются в названия арок.
- Осмысленное название арки/сезона показывается отдельной плашкой баннера; техническое «Часть 4» не дублируется. Расхождения количества сезонов источника и базы не выводятся служебным текстом на баннер.
- «Дандадан»: проверенный счётчик релизов в полной карточке согласован с двумя сезонами и 24 эпизодами. Для «Блича» пропущенный файл не блокирует метаданные остальных серий. Для поздних файлов «Ван Писа» учитываются абсолютные номера внутри TMDB-сезона.

Ограничение: карта метаданных не создаёт отсутствующий у источника сезон и не доказывает содержимое видеопотока. При неоднозначном или противоречивом сопоставлении чужие описания не подставляются. Наличие собственного кадра и русского описания зависит от внешней базы; общей картинки сериала недостаточно, чтобы обещать кадры всех эпизодов.

## Публикация и проверка

Изменения после 0.5.25 распределены по версиям 0.5.26–0.5.28. Для текущего выпуска выполняются сборка и проверки затронутых сценариев. Полные повторные локальные аудиты и скриншоты не требуются. Публикация только в GitHub/main и GitHub Pages; сервер Lampac остаётся без обновления.
