# Единый каталог — 0.5.100–0.5.101

## Обновление 0.5.114

«Фильмы», «Сериалы», «ТВ-шоу» и «Мультфильмы» получили фильтр по стране производства. Он сочетается с жанром, годами и сортировкой. Сетка использует TMDB Discover для этих запросов. При выбранном CUB или Trakt рядом с фильтрами показан источник выдачи.

| Раздел | Порядок и изменения |
| --- | --- |
| Фильмы | В тренде, новинки, высокий рейтинг, ожидаемые и российские фильмы. Общая выдача уже сортируется по популярности. Для жанров есть отдельный фильтр. |
| Сериалы | В тренде, новинки и текущий эфир, затем рейтинг, завершённые, ожидаемые и страны. Страновые списки включают архив. «Корейские дорамы» доступны из «Сериалов» и сортируются в полном списке. |
| ТВ-шоу | Сейчас смотрят, новинки, рейтинг, реалити и соревнования, ток-шоу. Страна выбирается отдельно, поэтому каталог включает зарубежные шоу. |
| Мультфильмы | В тренде, новинки, высокий рейтинг, российские, мультсериалы, полнометражные и семейные. Страницы фильмов и сериалов объединяются по выбранной сортировке. |
| Аниме | «Новинки сезона» используют один порядок в ряду и полной выдаче. При выбранном Trakt сезонный ряд загружает TMDB. |

В русской выдаче каталога карточка требует постер и русский текст в названии или описании. Отсутствие широкого фона не исключает карточку. При фильтрации пустых страниц поиск продолжения идёт дальше по источнику. «Ещё» остаётся видимой, когда ряд выходит за пределы окна или источник сообщает о следующих страницах.

Позднее указание пользователя заменяет прежние ряды в фильмах, сериалах и мультфильмах. Раздел открывает штатную сетку Lampa. Четыре независимых параметра: подборка, жанр, популярные/рейтинг/новые, годы. В выборе подборок сохранены все определения прежнего плана, кроме жанровых. «Все подборки» означает общий каталог, а не склейку повторяющихся превью. Жанр и годы сужают выбранную подборку. Недельный Trending не поддерживает эти фильтры, поэтому при их выборе используется TMDB Discover.

По умолчанию доступны архивные сериалы: прежняя граница четырёх лет не применяется к общему списку. «Новые» без ручных лет ограничены свежими релизами. Ручной диапазон 1870–текущий год проверяется до запроса. Для мультфильмов обе страницы форматов сливаются по сортировке; следующая порция одного формата запрашивается перед сравнением с хвостом другого. Идентичный числовой ID movie и tv остаётся двумя проектами. Новые параметры сохраняются отдельно по четырём категориям, прежние настройки рядов не удаляются.

Полные списки актёров используют movie_credits/tv_credits, включая cast и crew, с удалением повторов по ID внутри формата. Компании используют Discover with_companies для обоих форматов. Телеканалы используют только with_networks в TV: фильмы канала не выдумываются, пустая вкладка предлагает перейти к сериалам. Обе вкладки открываются с фильмами по умолчанию. Карточки без постера в фильмографии сохраняются. Загрузка дальнейших страниц, открытие карточки и возврат остаются штатными.

Главная сохраняет «Сейчас смотрят» и историю без изменений. Её три добавленных ряда используют скользящие последние 12 месяцев, сегодняшнюю верхнюю дату и сортировки по дате/популярности. На установленной Lampa 10 ноября проверены текущие пять рядов; годовые ряды содержат проекты 2026 года. В стандартном аниме сохранён порядок: сейчас смотрят, сейчас выходит, новинки текущего квартала, популярные, рейтинг, завершённые, полнометражные, ожидаемые. В Shikimori первым остаётся общий популярный список, затем текущие и сезонные; будущие анонсы отделены. Пользовательский порядок сохраняется.

Проверка публичных ответов 10 ноября: все пути текущего TMDB-плана фильмов, сериалов, мультфильмов и стандартного аниме через настроенный lampac.rest/tmdb/api/3/ вернули HTTP 200; первые страницы содержали 20 результатов, у ожидаемого аниме — 9. Все семь запросов Shikimori вернули по 24 результата. Проверялись дата/квартал и параметры, не только наличие карточек. Это проверка метаданных, не доступности видеопотоков. Стандартные CUB-ряды дополнительно проверяются на установленной Lampa; транспорт и порядок аниме не переписаны.

Настройки: управление рядами оставлено для главной, стандартного аниме и Shikimori. Параметры новых списков находятся непосредственно над сеткой. Сброс фильтров меняет только четыре ключа фильтров, без очистки истории, аккаунта и порядка главной.

Проверки: catalogue-browser.test.cjs проверяет диапазон, архивы и слияние 80 проектов без пропусков; catalogue-grid.cjs — Chromium/WebKit, ПК/ТВ/телефон, фильтры, пульт, все страницы актёра, вкладки студии и канал без подмены ID. Геометрия карусели, шапка и фон карточки проверяются отдельными сценариями. Физический телевизор не заменяется эмуляцией.

Официальные параметры: [TMDB Discover movie](https://developer.themoviedb.org/reference/discover-movie), [Discover TV](https://developer.themoviedb.org/reference/discover-tv), [Shikimori API](https://shikimori.io/api/doc/1.0/animes/index).

В 0.5.101 к общей сетке добавлены ТВ-шоу: четыре фильтра, жанры реалити/ток-шоу отдельно от подборок, российский отбор сохранён. Общий список включает архив, ручные годы используют тот же валидатор. Прежний порядок и скрытие рядов остаются в хранилище и не сбрасывают параметры других разделов.
