# Источники и каталог: 0.5.17

- Общий список реальных источников Lampac для фильмов, сериалов и аниме. Новые источники не теряются; неизвестный язык — отдельная группа.
- Переключатели по языкам используют существующий alc_auto_src_off; исключают выбор в штатном Online и запросы автопилота. Штатная серверная проверка доступности остаётся: публичный API Lampac не принимает список исключений.
- Сохранить порядок сервера, данные аккаунта, транспорт, отмену запросов и выбор последнего просмотренного источника. Политика видимости входит в ключ кеша discovery.
- KinoAPI для дорам и российских реалити/ток-шоу: только документированные страны/жанры, с проверкой результата; корректные страницы по Подробнее. Личный ключ переносится штатным восстановлением настроек по уточнению пользователя. Без ключа или при отказе — прежние подборки.
- Проверить сборку, модульные сценарии и актуальный CI/Pages; скриншоты не создавать.

Проверка lampac.rest: фильмы — 18, сериалы — 15, аниме — 22; объединение — 28 уникальных модулей (количество не означает работоспособность каждого). Zetflix в публичных списках отсутствует.

Следующий отдельный объём: единая модель релизов аниме для меток подборок, подробной карточки, онлайна и торрентов; связи франшизы MAL/Shikimori. Текущие API-данные не считать безошибочными, ручные исключения по названиям не добавлять.
