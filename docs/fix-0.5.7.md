# 0.5.7 — Подписи сезонов и описания эпизодов

- Сохранить число эпизодов после ухода с выбранного сезона. Ключ кеша учитывает произведение, язык, источник и его нумерацию.
- Для подписи использовать явную группу TMDB независимо от списка файлов другого/загружаемого сезона; для метаданных выбранных файлов сохранить проверку соответствия количества.
- Ошибку или неполный ответ TMDB не кешировать навсегда; один отложенный повтор с общей очередью и максимум двумя одновременными запросами. Без постоянного опроса и перезагрузки экрана.
- Поздний ответ другого сезона/источника/экрана не должен изменять текущие карточки. Сохранить штатные URL и ключи Timeline.
- Проверить части 5/5/7/8, русский текст второй части, задержки/ошибки запросов и переключения. Сборка, обязательные тесты, CI и Pages; скриншоты не делать.

Перед публикацией: сборка ES5; 365/365 тестов; 7 проверок bootstrap и 3 Online; online-polish и voice-initial в Chromium/WebKit. Проверены конфликтующий временный список файлов, сохранение подписи после ухода с сезона, совместный повтор запроса и восстановление русских описаний второй части без изменения Timeline. Данные групп 5/5/7/8 и русские описания канонических серий 1:6–1:10 подтверждены публичным API TMDB. Физические устройства в этом проходе не проверялись.
