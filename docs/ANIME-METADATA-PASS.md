# Проверка метаданных аниме — 0.5.15

- Качество соответствует конкретному аниме и году; фильм, продолжение, совпадение части названия и явный upscale не повышают метку сериала. Настоящий подходящий 4К-релиз допускается.
- Старые неоднозначные метки аниме не используются повторно, остальные кеши сохраняются.
- Shikimori: номер сезона по явному названию либо однозначной цепочке TV-продолжений, без фильмов/OVA и без ручных исключений по названию. Ошибка API не превращается в сезон 1.
- Стандартный каталог: для аниме, объединённого TMDB в один сезон, верхняя метка использует штатное splitEpisodesIntoSeasons Lampa. Только вышедшие серии, без изменения координат Timeline и воспроизведения.
- Ограниченные запросы при фокусе, кеш и совместное ожидание одинаковых карточек; без загрузки всех сезонов каталога.
- Сборка, тесты, проверки Python и актуальный CI/Pages перед завершением. Без скриншотов и без заявления о проверке физического ТВ/iPhone.

Проверено на реальных ответах API 2026-11-04: TMDB 95479 — 59 серий в одном каноническом сезоне → метка Сезон 3 / 12; TMDB 240411 — 24 серии в одном → Сезон 2 / 12. Shikimori 16498 → сезон 1, 25777 → сезон 2. Физические устройства в этом проходе не проверялись.
