# KinoAPI: ограниченный проход

- Личный ключ вводится отдельно от переключателя «Да / Нет»; не включать его в код, Git, URL или логи. По уточнению пользователя ключ должен входить в штатную резервную копию настроек для восстановления на других устройствах.
- KinoAPI дополняет метаданные аниме и точное сопоставление Shikimori → TMDB.
- Данные проверять по координатам и полноте. Не принимать список MAL-релизов за количество сезонов без соответствия серий.
- Полный абсолютный список провайдера разбивать по подтверждённым аркам; название, кадр, дата и описание относятся к исходной серии.
- Не менять ссылки воспроизведения, индексы файлов и ключи Timeline.
- Ограничить параллелизм, частоту, очередь и кеш; при отсутствии ключа или отказе API сохранить штатный путь.
- Исправить скрытие метки после касания подписи карточки; обязательные сборка, тесты и CI.
- Не делать скриншоты; физические iPhone/Philips не считать проверенными.

Ограничение базы: KinoAPI /seasons для Jujutsu Kaisen также возвращает один сезон; его маппинг пока не покрывает второй MAL-релиз на уровне всех эпизодов. Не исправлять это вручную по названию. Связей франшизы в текущем OpenAPI нет.
