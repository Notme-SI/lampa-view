# Каталог Trakt

Trakt предоставляет состав и порядок популярных и текущих подборок. Карточки с проверенным сопоставлением TMDB используют штатные сведения и поиск Lampa. Изображения приходят в ответах Trakt; дополнительные запросы для каждой карточки не выполняются. Элементы без TMDB ID пропускаются, чтобы не открыть другой фильм по совпавшему числовому ID.

1. Войдите в Trakt и откройте [создание API-приложения](https://trakt.tv/oauth/applications/new).
2. Укажите имя `Lampa View` и описание личного каталога. Для текущей формы с типом **Development** укажите **Redirect URIs:** `http://localhost/callback` и **Allowed origins:** фактический адрес Lampa без пути, например `http://lampac.rest`. Development принимает только localhost, 127.0.0.1 или ::1 в redirect. Публичные подборки не используют перенаправление OAuth. Публичное приложение для других пользователей требует отдельного согласования Production с Trakt; Development предназначен для личного тестирования.
3. Скопируйте **Client ID** созданного приложения.
4. В Lampa откройте **Настройки → L A M P A → Каталог и поиск → Trakt** и включите его. По умолчанию Trakt выключен. При первом включении появится запрос Client ID — вставьте значение. Пустой ввод оставляет Trakt выключенным.
5. Откройте **Настройки → Остальное → Основной источник**, выберите **Trakt** и заново откройте главную или категорию. Переключатель плагина не меняет основной источник автоматически. При выключении Trakt его пункт убирается из списка; если он был выбран, восстанавливается прежний источник. Client ID сохраняется для повторного включения.

Нужен только публичный Client ID. Не вводите Client Secret, пароль Trakt или токен доступа. Настройка сохраняется локально на устройстве; готовый ключ в код расширения не включён.

Это каталог публичных подборок, без входа в личную медиатеку и синхронизации истории. Без Client ID возвращается ошибка настройки, а не подборки TMDB под названием Trakt. При сетевой ошибке или отказе API скрытая подмена каталога также не выполняется.

Для загрузки одновременно выполняется не более двух запросов. Ответы кешируются на десять минут, смена Client ID сбрасывает кеш и отменяет прежние запросы. Открытие «Ещё» сохраняет источник Trakt и страницу списка.

Справка: [официальное подключение API](https://developer.trakt.tv/docs/authentication-oauth), [каталоги и пагинация](https://trakt.docs.apiary.io/reference/movies), [формат изображений в полном ответе](https://github.com/trakt/trakt-api/issues/762).
