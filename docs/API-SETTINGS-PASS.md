# Ключи API: критерии готовности

- KinoAPI: «Да / Нет» и отдельное поле ключа, как у Trakt.
- Существующий ключ работает без повторного ввода; выключение сохраняет его, пустой ввод удаляет и отключает сервис.
- Ключи обоих сервисов входят в штатную резервную копию настроек Lampa и восстанавливаются на другом устройстве по запросу пользователя. Непрерывную синхронизацию не обещать.
- В описании обоих полей указать сайт получения ключа и перенос при восстановлении; ключ KinoAPI маскировать.
- Не добавлять личные ключи в исходники, Git, URL или логи.
- Проверить отмену первого ввода, старый ключ, выключение/включение и перенос на чистое устройство.
- Сборка, обязательные проверки, публикация и актуальный CI/Pages; без скриншотов.

## Уточнения этого прохода

- Разобрать SURS и предложить обновление подборок, не подключая чужой плагин целиком.
- Полный сквозной список аниме должен разбиваться на подтверждённые арки без обязательного ключа. Не создавать недоступные у провайдера серии.
- На онлайн-баннере: номер сезона и его название второй строкой; не повторять техническое «Сезон N».
