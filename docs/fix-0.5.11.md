# 0.5.11 — Подпись сезона на постере

Убрать «Часть» из верхней релизной метки и её подсказки. Использовать локализованное «Сезон» и номер опубликованной группы: для третьего канонического сезона с названием «Часть 4» метка «Сезон 4». Данные API, сопоставление серий, ключи Timeline и сведения о просмотре не менять.

Значки закладки/сердца/часов: контуры 1,6, общий размер и фон по теме, вставка после расчёта геометрии не должна отправлять их в центр постера. Нативные флаги/обработчики не менять. Проверить оба оформления в браузерном сценарии без снимков. Пустой ручной сезон не должен попадать в кеш недоступности всего источника.

Проверено: сборка ES5; 375/375 тестов; history-focus в Chromium/WebKit для ТВ и десктопа в обоих оформлениях; tv-captions; точечные сценарии метаданных и пустого ручного сезона. Снимки не создавались. Физический телевизор в этом проходе не проверялся.
