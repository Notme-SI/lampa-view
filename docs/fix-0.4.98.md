# Реальные браузер и Philips — 0.4.98

База 7cb2299 / 0.4.97: Verify plugin и Pages успешны.

Новое уточнение: у полностью просмотренной серии под карточкой больше не показывать полосу и время. Не объявлять сезон завершённым без всех серий законченного сезона; пустые дорожки онлайн-превью сохранять.

Пользователь предоставил доступ к Philips по ADB и вошёл в CUB в отдельном браузерном сеансе. Подтверждены Android 12, системный WebView 156.0.8078.47, Lampa Android 1.13.5. Физическая панель 3840×2160, действующий override UI 1920×1080. Настройки разрешения пока не менялись.

Подтверждённая причина несинхронизации: действующий TimeCode API сериализует пустой дамп без нулевой версии: {"rows":[]}. Клиент требовал явную конечную version и бесконечно оставался offline, не выгружая накопленное. Синтетические прежние тесты всегда возвращали version:0 и не воспроизводили реальный формат. Исправление должно принимать отсутствие версии только для пустого ответа; непустой ответ без курсора по-прежнему ошибка.

Критерии готовности: реальные подписи/метки помещаются на Philips во всех размерах; High загружает исходный баннер и подходящие постеры; браузер и ТВ сходятся по сохранённым записям; временная диагностика удалена; обязательные проверки и публикация завершены. Не менять панель истории Windows. Пароли, токены и полные URL с параметрами не сохранять в репозиторий и отчёт.


На реальном ТВ подтверждён viewport 960×540 / DPR 2. При Bigger заголовок Cyberpunk имеет font 8px / line 11.2px, но box 18.1875px против ink 20.6953px: ограничение в em считалось от шрифта ниже минимального WebView. Исправляется сам размер шрифта (минимум 8 CSS px), не геометрия карусели. Метка на узком ТВ переносит два целых сегмента, сохраняя читаемый шрифт и собственный фон.

Качество ТВ: native poster_size=w500 (High), но minimal_banner_quality=medium/revision=2; фактический баннер 1280×720 и постеры 500×750. Это подтверждает конфликт старой миграции. Revision 3 восстанавливает явно выбранный native High при таком старом конфликте и связывает оба штатных выбора; новые явные High/Medium сохраняют метку выбора. Очереди и ограниченный декодированный кеш не снимаются.

Обмен реально проверен: тестовая коррекция пустого ответа разблокировала клиентский upload. С резервной копией TimeCode.sql перенесены 88 записей только старой области того же CUB-профиля (79 отсутствующих хешей и более новые по авторскому времени); исходная область сохранена, другие области не объединялись. Импорт использовал штатный set API, реальные time/duration/percent/watched_at. Затем браузер и Philips получили по 118 записей и одинаковый MobLand: S1E2 / 1304 секунды / 42%. При этом обнаружено, что старое число сезонов в карточке ограничивало поиск истории: одинаковые файлы могли всё ещё показывать разные сезоны. Поиск теперь не обрезается локальным кешем числа сезонов.


Проверка сборки 0.4.98 на физическом Philips: Small/Normal дают заголовок Cyberpunk 24 CSS px при высоте текста 21.5; Bigger — 22.39 при 20.70. Год располагается ниже, зазор 1.59 px. Фактические High-изображения: баннеры original 2048×1152 и 3840×2160, постеры w780 780×1170. Штатный фокус истории показывает «Гангстерленд»: серия 2 / сезон 1 / серая дорожка с голубым заполнением / 21:44. Браузер и ТВ после загрузки сборки находят «Звёзды»: сезон 3 / серия 4 / 100%, без выдуманного времени. Разрешение Android и геометрия ТВ-карусели не менялись.

Проверки: регрессионные unit-тесты пустого дампа без version, отклонения повреждённого непустого дампа, старых сезонов карточки и согласования High/Medium; браузерная проверка 960×540/DPR2 с минимальным шрифтом Chromium 8 px, а также 1280/1920 и WebKit; тест обмена между двумя клиентами использует реальный пустой формат {rows:[]}. Изменено ожидание готовности строки в тесте навигации: ограниченное ожидание состояния вместо фиксированных 160 ms.
