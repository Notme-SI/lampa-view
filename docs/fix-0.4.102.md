# 0.4.102: нейтральное стекло

Уточнение пользователя: название «Стекло», визуально прозрачное/полупрозрачное оформление по видеореференсу, без синей палитры у меню, настроек, кнопок и карусели. В Lampa уже существует glass_style: использовать штатный класс glass--style и настройку прозрачности, сохраняя ранее выбранное пользователем значение при возврате к минималистичной теме. Старый выбор apple мигрирует в glass. Прежний src/apple.css заменён src/glass.css, синие заливки удалены. Блики, рамки, фокус и прогресс нейтральные; цвета самих постеров сохраняются. Размытие у панелей, на ТВ — ограниченный радиус, без фильтра на каждой карточке. Проверить обе темы, миграцию, нейтральность цветов, реальное размытие/прозрачность, геометрию и отображение на Philips. Системный режим не менять.

Первый вход AniLiberty: реальный публичный ответ по «Магической битве» содержит совпадающие сезоны с суффиксами 2 и 3, хотя метаданные TMDB сообщают один сезон. Старое ограничение по number_of_seasons отбрасывало их, затем folderTarget обходил штатный выбор сезонов. Теперь одноимённые номерные сезоны сохраняются независимо от устаревшего счётчика; фильм-приквел 0 и посторонние названия исключаются. UI сортирует сезоны численно, сохраняя оригинальные индексы API/URL. Реальный Lampac reset() не очищает приватные filter_find.season/voice, поэтому для Lampac сохранён штатный перезапуск компонента при смене провайдера: никакого переноса чужих сезонов/озвучек. В реальном ответе первого сезона AniLiberty 24 серии и 0 videos__button: вместо ложного выбора чужой озвучки отображается неинтерактивный статус «Озвучка источника».
