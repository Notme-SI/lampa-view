# Проверка MyShows и SURS — 13 ноября 2026

Проверены публичные скрипты без установки и авторизации в аккаунтах.

## MyShows

Источник — https://igorek1986.github.io/lampa-plugins/myshows.js, версия 1.0.12.

Если история уже ведётся в MyShows, интеграция полезна. Она получает список сериалов и просмотренных эпизодов, показывает непросмотренные серии, меняет статусы сериалов/фильмов и отправляет отметки из событий Timeline Lampa после заданного порога. Уже существующая история учитывается. В Lampa View есть совместимость с рядом `myshows://unwatched` — его состав и порядок не заменяются общими подборками.

Есть отдельный импорт истории из MyShows в Lampa/Lampac. Он сопоставляет проекты с TMDB и формирует записи завершения на 100%. При включённой серверной синхронизации обращается к `/timecode/batch_add` с идентификаторами пользователя/профиля, то есть требует соответствующий модуль TimecodeUser. Это импорт отметок о завершении. Реальную минуту остановки из такого импорта восстановить нельзя.

Внешний плеер должен возвращать timecode, который доходит до Timeline Lampa. Само наличие MyShows не добавляет такую возможность плееру.

### Авторизация

Описание поля пароля утверждает, что логин и пароль нигде не сохраняются. Реализация этому не соответствует. Обработчик поля вызывает `de('myshows_password', value)`, а `de` записывает значение в `Lampa.Storage.set` без шифрования. `password: true` маскирует только поле ввода. Ключи привязаны к профилю. Функция `ae` сначала отправляет логин/пароль на `https://myshows.me/api/session`, затем при неудаче использует сторонний прокси `https://myshows.igorek1986.ru/myshows/auth` или адрес из `auth_proxy`.

Вызовы `__NMSync.patch` также присутствуют, но поведение стороннего механизма синхронизации и его исключений в этой проверке не исследовалось. Нельзя считать доказанным ни отсутствие, ни наличие передачи пароля через этот механизм.

Рекомендация — интеграция имеет смысл для пользователя MyShows, особенно для отметок целых эпизодов и статусов. Для включения в Lampa View сначала нужен безопасный поток авторизации без сохранения пароля и проверка сопоставления сезонов аниме. Автоматическая установка и изменение аккаунта не выполнялись.

## SURS

Источник-загрузчик — https://aviamovie.github.io/surs.js. Для современного API Lampa он загружает https://aviamovie.github.io/v3/surs.js, `/v3/surs_nav_buttons.js`, `/v3/surs_rows.js` и https://aviamovie.github.io/surs_select.js. Проверен текущий модуль 3.1. Без прежнего снимка той же версии нельзя достоверно датировать каждое изменение.

Текущая реализация включает подборки стримингов/телеканалов, жанров, студий, франшиз, актёров, регионов и годов, недавние/ближайшие эпизоды и продолжение просмотра. Есть загрузка рядами по девять, шестичасовой кеш запросов TMDB и отдельный кеш поиска актёров/коллекций на 30 дней. Это не гарантирует более плавную работу само по себе. Модуль также случайно перемешивает некоторые ряды и использует широкие карточки.

В `surs_select.js` доступны дата выхода, рейтинг, популярность и кассовые сборы для фильмов, а для сериалов — число голосов. В основном модуле `revenue.desc` подписан как «Интерес зрителей», хотя запрос сортирует именно по сборам.

### Изменения Lampa View 0.5.163

Подборки добавлены в существующий фильтр «Все подборки» внутри категорий.

- Фильмы — кассовые сборы и много оценок.
- Сериалы — много оценок и все сети/платформы из проверенного справочника.
- Мультфильмы — кассовые сборы полнометражных работ, много оценок, сети и студии из справочника.
- Сортировка теперь сохраняет число оценок и кассовые сборы. Сборы доступны для фильмов и полнометражных мультфильмов.
- Пункты с одинаковым запросом удаляются. Жанры, страны и годы остаются отдельными фильтрами.

Боковое меню и набор рядов главной от этого не расширяются. Непроверенные или ошибочные ID сетей из SURS не копируются. Выполнена независимая реализация на существующем справочнике Lampa View.
