# Проверка после 0.5.67: 0.5.68

Работа продолжается. Этот документ не объявляет исходный список замечаний закрытым. Публикация только GitHub; сервер Lampac не изменяется.

## Изменения

- Объединённые части получают метаданные до проверки отдельного релиза, которая раньше отбрасывала сезон SAO из 23 серий.
- Номер серии и часть помещаются в один flex-контейнер; учтён создаваемый vendor элемент nova-card__tag.
- Недоступная озвучка одной части не удаляет доступные файлы последующей части. Пропуски сохраняются. Нулевой выпуск не сдвигает обычные серии.
- Отсутствующая или короткая карточка TMDB не обрезает части с явным непрерывным соответствием релизов. Это ещё не полное устранение зависимости структуры от TMDB.
- Для подтверждённых частей добавлено получение метаданных по MAL ID из KinoAPI, при включённой интеграции. Чужие MAL ID и дубли координат отклоняются. Ключи не добавлены в код.
- Язык запроса и кеша учитывается явно. По последнему указанию пользователя при отсутствии русского названия показывается «Серия N», английское описание не выдаётся за перевод.
- В Shikimori сразу загружаются все семь оставшихся подборок. Только «Все» исключена. Проверены настройки видимости и последовательная пагинация в штатном компоненте.
- Кнопка «Сезоны и фильмы» перенесена к заголовку, меню ограничено по ширине и высоте и привязано к кнопке. Отдельные релизы не удаляются из меню по общему TMDB ID. Пересказы вынесены из основной истории.
- На узком экране убрана подложка таймкода. Размер штатных «Настроек» не изменён.

## Данные, проверенные 7 ноября 2026

Публичные ответы Kodik, без запуска видео: Mushoku S1 AniDUB - 11 + 12 = 23; S2 Crunchyroll.Subtitles - 12 + 12 = 24 обычные серии и отдельный выпуск 0. Это проверка данных и алгоритма, не установленного интерфейса новой версии.

Pokemon: отдельный релиз Advanced Generation найден и возвращает 191 файл с номерами 1..193, без 101 и 121, в папке 2. Старый релиз 1997 года при выборе общего pick возвращал папки 23/27. Ранние сезоны пока не считаются восстановленными. Автоматически делить найденные файлы по числам сезонов TMDB нельзя: границы не подтверждены.

Графы семи франшиз сохранены в обезличенной тестовой фикстуре. Проверяются части SAO, Mushoku, Jojo, последовательность Jujutsu Kaisen и Kusuriya, отделение summary. Полнота Pokemon и Black Clover этим тестом не доказывается.

В установленной 0.5.67 баннер «Звёзды в джунглях» уже имел URL original, натуральный размер 1920x1080 и не имел CSS filter у изображения и родителя. Его разрешение не объявляется новым исправлением; визуальное сравнение исходника ещё требуется.

## Незакрытые проверки

- Установленная новая сборка: реальный DOM и каскад тегов, меню франшизы, переход в нужный релиз, мышь/пульт/касание.
- Покемоны: идентичность ранних релизов и границы сезонов.
- Моб Психо / Гинтама: сохранность сезонов и озвучек в живом интерфейсе.
- Источники кроме Kodik: общая метадата уже используется, но поиск отдельных потерянных релизов пока специфичен для Kodik. Универсальное восстановление не реализовано.
- Русская полнота Bleach, Soul Eater, Hunter, Dorohedoro, Tokyo Revengers и ответы KinoAPI с настроенным ключом.
- Постеры и классификация «Лазаря», реальная догрузка всех страниц Shikimori.
- Качество исходника баннера, телефонный таймкод и отсутствие скачков структуры.

Актуальная OpenAPI KinoAPI описывает перевод MAL-запросов эпизодов в координаты TMDB. Наличие MAL resolver само по себе не заменяет независимую структуру релизов. Источники: https://kinoapi.lampac.dev/docs и https://kinoapi.lampac.dev/openapi.json.
