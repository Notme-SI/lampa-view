# 0.5.3 — Нумерация частей и iPhone

- Подтверждено публичным API: у источника Pizdatoehd / Дубляж «Люпен» содержит 5/5/7/8 серий. В TMDB — 10/7/8, с названиями «Часть 3» и «Часть 4».
- Использовать явную альтернативную группировку TMDB при расхождении числа сезонов. Проверять число групп, общее количество серий, сеть и количество реальных файлов выбранного сезона. При неоднозначности не подставлять метаданные другого сезона. Без ручной таблицы исключений по названиям.
- Локализованные название/описание/рейтинг/кадр получают канонические координаты из группы; URL воспроизведения и существующие ключи Timeline остаются штатными. Сохранить ограниченные запросы, кеш и защиту от позднего ответа.
- На карточке использовать опубликованное название части; различать число частей и группировку сезонов.
- iPhone из Safari: проверить ранние viewport-fit / standalone status bar и безопасный верхний отступ; фон под системной строкой, элементы управления ниже выреза. Проверка на физическом iPhone остаётся за пользователем.
- Сборка, тесты сопоставления, обе темы, CI и Pages. Скриншоты не делать.

Проверено: сборка ES5; 356 тестов общего набора до добавления проверки названия части, затем все 8 тестов series-status; Chromium/WebKit в desktop/TV/mobile для оформления, карточки и Online. Ранний HTML и загрузчик установлены на lampac.rest с резервной копией, HTTP подтверждает метатеги до загрузчика. Физический iPhone не проверен.

Проверка пользователя: старый ярлык сохранил полосу, новый с black-translucent дал фон сверху, но укороченное окно и чёрную область снизу. Принудительный прозрачный status bar и добавочный safe-top отменены; использовать штатный default. Не обещать произвольный фон под системной строкой современного iOS.

CI выявил WebKit/TV: выбранная последняя карточка фильмографии могла остаться вне экрана. Сверять видимость после отложенного добавления карточек даже при неизменном размере слота; исправлять через штатный Scroll с его ограничениями, без создания всего каталога сразу. Тест сохраняет проверку всех 27 работ и добавляет восстановление видимости после сброса нативного scroll при неизменном размере.

Причина дрейфа WebKit/TV: правило ускоренной TV-анимации имело больший CSS-приоритет, чем штатный .notransition. Поэтому Scroll.immediate оставался анимированным, а следующий расчёт читал промежуточные координаты. Вернуть приоритет отключению перехода; сохранять проверку устойчивой видимости.
