# Изменения

## 0.4.30

- Удалены личные адреса из исходников, тестовых данных и документации. Плагин не назначает резервный сервер парсера.

## 0.4.29

- Быстрые превью видимых карточек с последующей загрузкой оригиналов, ограничение фоновых загрузок.
- Отложенная предзагрузка соседних баннеров и последовательное повышение качества выбранного баннера.
- Отдельный публичный репозиторий, GitHub Pages, ранняя заставка, SVG/ICO и инструкция установки.

## 0.4.28

- Среднее, высокое и максимальное качество изображений, максимальное по умолчанию.
- Плавная прокрутка колёсиком, кнопки возврата, сохранение штатного фокуса и навигации.
